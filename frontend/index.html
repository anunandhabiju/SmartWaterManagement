🎓 Data Structures Viva Note: Fixed/Bounded Arrays
Tanks are stored in a contiguous array of structs (`Tank g_tanks[MAX_TANKS]`). Array elements offer O(1) direct index lookup. Water addition strictly verifies the upper boundary: current_level + amount <= capacity, while water deduction prevents negative underflow: current_level - amount >= 0.

🎓 Data Structures Viva Note: Binary Search Tree (BST)
Areas are managed as dynamically allocated nodes (malloc/free) in a Binary Search Tree keyed on unique area_id. BST search and insertion operate in average O(log n) time for balanced configurations and O(n) worst-case if skewed. Performing an Inorder Traversal (Left $\to$ Root $\to$ Right) inherently retrieves and displays all areas in ascending numerical order of their Area IDs! Duplicate IDs are rejected at insertion.

Consumer Complaints Circular Queue

Implemented in C as a Circular FIFO Queue with bounded capacity and modulo index arithmetic.

Live Circular Queue Buffer (Slots):

Order Complaint ID Timestamp Area Name Issue Category Description Priority Status
No pending complaints in queue.
🎓 Data Structures Viva Note: Circular Queue
Unlike a linear array queue which suffers from false-overflow or requires expensive shifting, a Circular Queue treats the array as a ring using modulo arithmetic: rear = (rear + 1) % MAX_CAPACITY and front = (front + 1) % MAX_CAPACITY. It operates strictly in FIFO (First-In, First-Out) order in O(1) enqueue and dequeue operations. When a complaint is processed, it is dequeued from this circular queue and a maintenance work order is dynamically inserted into the Singly Linked List!

🎓 Data Structures Viva Note: Singly Linked List
Maintenance records are managed via a singly linked list with nodes containing dynamic pointers: struct MaintenanceNode *next. New work orders are inserted at head in O(1) time using malloc(). Deleting resolved records traverses the list and safely frees node memory with free(), rewiring the preceding node's next pointer and properly adjusting the head when the first node is removed.

🎓 Data Structures Viva Note: Graphs & BFS/DFS
The pipeline grid is modeled as an Adjacency List Graph in C (array of vertices where each vertex has a linked list of edges). Breadth-First Search (BFS) traverses level-by-level using an integer queue to discover the minimum hop route between reservoir and consumer, accumulating pipeline distance. Depth-First Search (DFS) explores connected subgraphs to detect network partitioning when a pipeline fails. Note: This performs topological connectivity analysis; it does not model hydraulic pressure head or friction factor calculations.

Simulates pipeline bursts, updates water balances, and triggers automated emergency complaints.

Deducts water from the supply network and logs non-revenue water loss.

Automated Cascading Workflow:

  1. The simulated water loss is deducted from the source storage tank.
  2. The cumulative system leakage loss metric is updated in memory.
  3. A High Priority Complaint is automatically enqueued into the Circular Queue with simulated sensor alarm details.
  4. When operators process the queue, a field maintenance work order is dynamically scheduled.
